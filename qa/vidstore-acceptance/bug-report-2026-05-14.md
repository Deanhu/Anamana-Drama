## P1 — 阻塞级

### BUG-01: 归属人字段缺失

| 项目 | 内容 |
|------|------|
| 来源 | RO-013, DR-004, DR-007 |
| Spec | §3 基本字段 — 归属人（Owner）自动填入当前登录账号，只读 |
| 影响页面 | 创建页 + 详情/编辑页均缺失 |
| 现象 | 基本字段区域无"归属人"字段，创建时无法自动填充，编辑时无法查看 |
| 期待 | 字段自动填充当前登录用户名，不可编辑 |
| 截图 | `screenshots/2026-05-14T02-52-48-040Z-basic-fields-missing.png` |
| | `screenshots/2026-05-14T03-07-30-977Z-detail-owner-missing.png` |

### BUG-02: 下线操作无二次确认弹窗

| 项目 | 内容 |
|------|------|
| 来源 | SF-005 |
| Spec | §7.2 状态机 — 已发布→下线需确认弹窗"下线后 App 端将不再展示该漫剧，确定下线？" |
| 影响页面 | 详情页（已发布状态的剧集） |
| 现象 | 点击"下线"按钮后直接跳转至列表页，状态变为已下线，无任何确认提示 |
| 期待 | 弹出确认弹窗，用户确认后才执行下线操作 |
| 截图 | `screenshots/2026-05-14T06-23-08-085Z-offline-confirm-missing.png` |

## P2 — 需对齐

### BUG-03: 语言筛选下拉与 Spec 不一致

| 项目 | 内容 |
|------|------|
| 来源 | IR-006 |
| Spec | §5 多语言 — 固定 15 种语言：EN, ZH, JA, KO, ES, FR, TH, PT, DE, AR, HI, ID, VI, TR, RU |
| 影响页面 | 列表页筛选栏 |
| 现象 | 缺少 ZH, AR, HI, VI；多出 IT, SV, NL, FIL |
| 期待 | 下拉选项精确匹配 Spec 定义的 15 种语言 |
| 截图 | `screenshots/2026-05-14T03-19-07-900Z-language-options-mismatch.png` |

### BUG-04: 字幕矩阵 hover 操作按钮缺失

| 项目 | 内容 |
|------|------|
| 来源 | ST-007 |
| Spec | §6 剧集管理 — 已上传字幕的单元格应支持预览/替换/删除操作 |
| 影响页面 | 详情页 → 剧集管理 → 字幕矩阵 |
| 现象 | 已上传字幕条目只显示文件名，hover 时无"预览/替换/删除"操作按钮 |
| 期待 | hover 显示操作按钮；或始终显示操作入口 |
| 截图 | `screenshots/2026-05-14T04-06-17-886Z-subtitle-actions-missing.png` |
| 备注 | 测试脚本未执行 hover 动作，需人工确认是否为 hover-reveal 模式。如确认无操作入口则为本 bug |

---

### BUG-05: Google Fonts 加载失败

| 项目 | 内容 |
|------|------|
| 来源 | IR-009 |
| Spec | 无直接对应（属于基础资源可靠性） |
| 影响页面 | 全站 |
| 现象 | `fonts.googleapis.com` 返回 `ERR_CONNECTION_RESET`，导致 Space Grotesk / Inter / Noto Sans SC 字体无法加载 |
| 期待 | 关键字体资源可正常加载，不依赖被墙域名 |
| 建议 | 字体资源迁移至国内 CDN 或本地托管 |
| 截图 | `screenshots/2026-05-14T03-19-07-900Z-resource-failed.png` |

### 建议优先级

1. **BUG-01**（归属人）— 核心字段缺失，影响数据归属追踪
2. **BUG-02**（下线确认）— 危险操作无保护，可能导致误操作
3. **BUG-03**（语言列表）— 数据一致性，影响多语言覆盖
4. **BUG-04**（字幕操作）— 功能完整性
5. **BUG-05**（字体 CDN）— 视觉体验，建议国内 CDN

### 通过的测试

以下模块验收通过，无 bug：
- 登录与导航
- 列表页卡片字段、完成度指示器
- 详情页素材区、多语言区
- 剧集管理 Tab、剧集/字幕矩阵布局
- 搜索筛选、排序控件
- 创建漫剧（填写必填字段 + 保存草稿）
- 上传封面图
- 状态流转：草稿→发布、下线→重新发布
- 无"删除整部漫剧"入口（符合 Spec）
