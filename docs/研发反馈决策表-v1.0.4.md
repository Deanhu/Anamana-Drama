**Q10 状态机 — 简化三态（方案 A，已确认）**

```
┌──────────────────────────────────────────────────┐
│                                                    │
│  [新建] ──→ 草稿 ──→ 已发布 ──→ 已下线           │
│              ↑                      │              │
│              └──────────────────────┘              │
│                 (重新发布，回到已发布)               │
│                                                    │
└──────────────────────────────────────────────────┘
```

| 状态转换 | 触发方式 | 校验规则 | 入口位置 |
|---------|---------|---------|---------|
| 新建 → 草稿 | 首次点击「保存草稿」 | 仅漫剧名称必填 | 详情页操作栏 |
| 草稿 → 已发布 | 点击「保存并发布」 | 全部必填项（名称、作者、剧来源、制作模式、封面） | 详情页操作栏 |
| 已发布 → 已下线 | 点击「下线」 | 二次确认弹窗：「下线后 App 端将不再展示该漫剧，确定下线？」 | 详情页操作栏 |
| 已下线 → 已发布 | 点击「重新发布」 | 重新校验全部必填项 | 详情页操作栏 |
| 已发布 → 编辑 → 保存 | 点击「保存」 | **保持已发布**，不回退到草稿 | 详情页操作栏 |
| 已下线 → 页面表现 | — | 详情页只读，所有字段不可编辑，操作栏仅显示「重新发布」 | — |

**Q11 翻译机制 — 纯手动触发（已确认）**

| 规则 | 说明 |
|------|------|
| 触发方式 | **纯手动**，无自动触发。用户点击按钮才翻译，保存/发布时不会自动翻译 |
| 批量触发 | 多语言区顶部「一键翻译全部文本」按钮，翻译所有未翻译的语言 |
| 单语言触发 | 每张语言卡片上加「翻译」快捷按钮，只翻译该语言 |
| 翻译中状态 | 按钮禁用 + spinner，翻译完成后恢复 |
| 翻译失败 | 显示错误 toast，该语言翻译按钮变为「重试翻译」 |
| 覆盖保护 | 已有人工修改的翻译再次触发时弹出确认（见 #27） |
