## 1. 页面整体结构

### 1.1 漫剧详情页（drama-detail.html）

页面分为两个 Tab：

| Tab | 名称 | 内容 |
|-----|------|------|
| Tab 1 | 基本信息 & 素材 | 基本信息表单 + 素材管理 + 多语言内容管理 |
| Tab 2 | 剧集管理 | 字幕语言选择器 + 批量上传面板 + 剧集×字幕矩阵 |

### 1.2 页面顶部信息

| 元素 | 说明 |
|------|------|
| 页面标题 | `编辑漫剧: {漫剧名称}` |
| 状态 Badge | 显示当前状态：草稿 / 已发布 / 已下线 |
| 最后保存时间 | 格式 `YYYY-MM-DD HH:mm` |
| 操作按钮 | 「保存草稿」+「保存并发布」 |

## 2. 素材资源规格

| 资源类型 | 尺寸 | 大小限制 | 格式 | 必填/选填 | 备注 |
|----------|------|----------|------|-----------|------|
| 剧默认栏位封面 | 516×765px | ≤300KB | 图片 | **必填**（英语） | 每语言独立一张；logo 设计在封面内，作为一张完整图片上传 |
| 剧大封面 / 首页 Banner | 720×1067px | ≤500KB | 图片 | **必填**（英语） | 每语言独立一张 |
| 花絮视频 | - | ≤50MB | MP4 | 选填 | 不区分语言 |

**P0 已移除的资源**（不进入上传、校验和完成度统计）：
- 动态封面（MP4, 3-5秒）
- 动态 Banner（MP4, 3-5秒）
- Logo（200×200px PNG，品牌资产，不区分语言）

**素材交互要求**：
- 封面和首页 Banner 缩略图 hover 时显示半透明遮罩，提供「预览」和「重新上传」两个操作
- 点击「预览」弹出全屏图片预览弹窗
- 花絮视频放在「其他素材（选填）」折叠区内，默认收起

**视频上传约束（v1.0.7 补充）**：
- 视频必须按 **9:16 竖屏比例**上传
- 上传时系统需要检测视频尺寸/比例；非 9:16 需要报错并阻止通过
- 单集视频大小限制为 **≤300MB**
- 视频格式必须为 **MP4**
- 视频分辨率按 **1080P** 提供

## 3. 基本信息字段

### 3.1 字段清单

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 漫剧名称 | text | ✅ | 英文名称 |
| SeriesId | 只读展示 | - | 系统生成，格式 `#1000058`，不可编辑 |
| 作者 | select | ✅ | 从作者库下拉选择，作者管理见 §13 |
| 归属人 | 只读展示 | - | 自动填入当前登录账号，不可编辑 |
| 语言 | 只读展示 | - | 固定为英文（EN），不可编辑 |
| 剧来源 | select | ✅ | 枚举：全包采买剧 / 内部剧 / 外部合作剧 |
| 制作模式 | select | ✅ | 枚举：剧转剧 / 文生剧 / 漫转剧 / 成品剧 |
| 横竖屏 | radio | ✅ | 竖屏（默认）/ 横屏 |
| 类型（分类） | select | 否 | 枚举：恋爱 / 悬疑 / 奇幻 / 都市 / 古风 / 科幻 / 校园 |
| 标签 | 标签库多选 | 否 | 从标签库选择（多选下拉），标签管理见 §12 |
| 简介 | textarea | ✅ | 英文简介，≤500 字符，带实时字数统计 |

### 3.2 布局

- 基本信息和素材管理分左右两栏（`lg:grid-cols-2`）
- 归属人 + 语言同行；剧来源 + 制作模式同行；横竖屏 + 类型两列同行

### 3.3 标签交互

- 点击标签区域弹出标签库下拉面板
- 标签库列表自动过滤已添加的标签
- 点击标签项添加，已添加的标签自动从列表隐藏
- 每个标签显示为 pill 样式，带 × 删除按钮
- 标签颜色循环使用 4 种背景色
- 标签库维护见 §12
- **拖拽排序（v1.0.9 新增）**：已选标签支持拖拽调整顺序
  - 每个 pill 左侧带拖拽手柄图标（grip-vertical），鼠标悬停光标变 grab，暗示可拖
  - 拖动时显示紫色占位竖线，实时指明松手插入位置；鼠标在目标 pill 左半侧插其前面，右半侧插其后面；拖到空白区域放最后
  - 拖动中被拖 pill 半透明显示
  - **顺序即配置顺序**：拖拽后的排列顺序为最终保存顺序，透传至 API（§9 数据模型 `tags` 数组下标即顺序）
  - 拖拽排序仅影响当前剧集的标签展示与输出顺序，不改动标签库（§12）的全局配置

## 4. 多语言配置

### 4.1 基础规则
- 共 **15 个语种**：EN, ZH, JA, KO, ES, FR, TH, PT, DE, AR, HI, ID, VI, TR, RU
- **英语（EN）为必传语言且为原始语言**（基本信息中固定不可更改），其他 14 种不强制
- 多语言覆盖以下内容：

| 内容类型 | 多语言方式 | 英语要求 | 其他语言 |
|----------|-----------|---------|---------|
| 剧集名 | 英文手动填写 → 系统自动翻译 → 结果可编辑 | 必填 | 自动生成，可人工修改 |
| 封面 | 每语言独立上传 | 必传 | 选传 |
| 首页 Banner / 剧大封面 | 每语言独立上传 | 必传 | 选传 |
| 简介文本 | 英文手动填写 → 系统自动翻译 → 结果可编辑 | 必填 | 自动生成，可人工修改 |
| 字幕 | 在「剧集管理」中按集×语言矩阵上传 | 必传 | 选传 |

### 4.2 文本自动翻译约束
- **源语言**：英文
- **触发方式**：
  - 单语言：在语言详情面板中触发（点击「一键翻译」占位区域）
  - **全量批量**：多语言区标题栏提供「一键翻译全部文本」按钮，一次性触发所有非 EN 语言的剧集名和简介自动翻译
- **翻译结果**：必须展示在后台界面，运营可以直接编辑修改（剧集名 input、简介 textarea 均可编辑）
- **翻译状态**：区分「已翻译」（系统自动翻译完成，显示"自动翻译"标签）和「未翻译」（尚未触发翻译）
- **字数限制**：剧集名 ≤120 字符，简介 ≤500 字符，带实时字数统计，超限时计数器变红

### 4.3 素材上传结果展示
运营上传素材后，**必须能看到以下信息**：
- 上传是否成功（成功/失败状态，用 ✓/✗ 图标 + 颜色区分）
- 封面和首页 Banner 可预览缩略图，hover 显示「预览」+「重新上传」操作
- 剧集名和简介可预览文本内容
- 支持**编辑、修改、重新上传**（覆盖旧版本）

### 4.4 字幕相关约束
- 字幕内容**不需要**在后台编辑（"显示字幕内容没有意义，因为最终发现问题都是在 App 端" —— 需求方原话）
- 只需显示**上传状态**（成功/失败/未上传）
- 字幕文件名需展示（方便运营确认版本）
- **字幕语言码（v1.0.9 新增 `zh-Hant`）**：繁体中文作为新语种纳入字幕语言码白名单。文件名识别基础规则见《剧集视频与字幕文件识别规则 v1.0.8》，v1.0.9 对其做以下增量：
  - **语言码白名单**：en, zh, ja, ko, de, es, fr, it, nl, pt, sv, **zh-Hant**。`zh` 为简体中文，`zh-Hant` 为繁体中文，二者独立并存，不替换。
  - **语言码值标准依据**：`zh-Hant` 见 BCP 47 + ISO 15924（Hant）+ W3C 推荐，iOS/Android/Google/CLDR 一致采用；`zh-TW` 是按地区（台湾），`zh-Hant` 是按文字（繁体），本场景用 `zh-Hant` 不绑定单一地区。
  - **语言码 token 形式定义（正则升级，核心改动）**：v1.0.8 隐含语言码为 2 字母、不含连字符；v1.0.9 放宽为「由字母和连字符 `-` 组成，长度 2-6 字符，最多含 1 个连字符」。合法：`en`/`zh`/`de`/`pt`/`sv`/`zh-Hant`；非法：`zh-Hant-Extra`（多连字符）、`z`（1 字符）、`zh_Hant`（下划线非连字符）。
  - **完整 token 匹配**：识别时对下划线前/后的整个 token 精确匹配，不用前缀匹配。`zh-Hant_xxx.srt` 语言码是 `zh-Hant`，不可截断为 `zh`；`zh_xxx.srt` 是 `zh`（简体），不可误识别为 `zh-Hant`。
  - **两种命名格式切分（连字符不干扰下划线切分）**：
    - 格式 A（前缀）`{语言码}_{剧名}_{集数}.srt`：`zh-Hant_The Memory Mart_12_.srt` -> zh-Hant，第 12 集（第一个下划线前完整取出语言码）
    - 格式 B（后缀）`{集数}_{语言码}.srt`：`1_zh-Hant.srt` -> 第 1 集，zh-Hant（最后一个下划线后到扩展名前整体为语言码）
  - **样例补充**：合法 `zh-Hant_The Memory Mart_12_.srt`、`1_zh-Hant.srt`；非法 `zh_Hant_The Memory Mart_12_.srt`（误用下划线）、`zhHant_The Memory Mart_12_.srt`（无连字符，不在白名单）。
  - **验收用例**：合法识别 `zh-Hant_The Memory Mart_12_.srt` -> zh-Hant 第 12 集、`1_zh-Hant.srt` -> zh-Hant 第 1 集；非法拦截 `zh_Hant_...srt`、`zhHant_...srt`；前缀匹配回归 `zh_...srt` 识别为 `zh` 不可误为 `zh-Hant`。
  - **命名规则性质**：文件名命名规则为内部约定（非行业通用规范），研发必须严格按规则实现，不可假设标准库能解析。

## 5. 多语言内容管理 — UI 交互细节

### 5.1 整体完成度摘要条

在多语言区顶部显示全局完成度摘要：
- 进度条：`{完整语种数}/{总语种数} 语种完整`
- 分项统计 chip：剧集名 x/y、封面 x/y、Banner x/y、简介 x/y
- 字幕统计指向剧集管理 Tab
- 完成的分项用 mint 背景，未完成用 coral 背景

### 5.2 EN 区域（必填语言）

- 独立的可折叠 Accordion，默认展开，黄色（lemon）背景标题栏
- 标题栏右侧显示各项完成状态摘要：`剧集名 ✓ 封面 ✓ Banner ✓ 简介 ✓ 字幕 1/4`
- 展开后四栏布局：剧集名 | 封面 | Banner | 简介
- 底部显示字幕进度 + 「在剧集管理中管理 →」跳转链接
- 点击标题栏可折叠/展开（chevron 图标旋转动画）

### 5.3 其他语言 — 卡片网格

- 非 EN 语言以紧凑卡片网格展示（`grid-cols-2 md:grid-cols-3 lg:grid-cols-4`）
- 每张卡片显示：语言代码 + 语言名称 + 剧集名/封面/Banner/简介/字幕的 ✓/✗ 状态
- 全部完成的卡片：mint 边框 + mint 浅色背景
- 未全部完成的卡片：默认边框 + 白色背景
- Demo 示例：ZH 为完成态（剧集名/封面/Banner/简介均完成），JA 为未完成态（缺简介），用于 QA/研发对照两种 UI 状态
- 卡片 hover 有上浮 + 阴影效果

### 5.4 语言详情面板

- 点击任意语言卡片，在卡片网格下方展开详情面板
- 被选中的卡片显示 purple 描边高亮
- 详情面板内容：四栏布局（剧集名 | 封面 | Banner | 简介）+ 字幕进度 + 「管理字幕 →」跳转
- 面板顶部有关闭按钮

### 5.5 语言管理

- 标题栏显示当前语种数量 badge（如 `3 语种`）
- 语言增删通过「剧集管理」Tab 中的语言选择器统一管理（搜索面板 + 全选/取消全选）
- 搜索面板顶部显示「已选 x/15 种语言」计数
- 移除语言需二次确认，提示"数据不会丢失，重新添加即可恢复"

## 6. 剧集管理 — 交互细节

### 6.1 页面头部

- 显示上传进度：`已上传 {n} 集` + 进度条
- 操作按钮：「批量添加剧集」+「批量上传字幕」

### 6.2 字幕语言选择器

- 合并在矩阵上方的灰色工具栏中
- 已选语言显示为 chip 列表，每个 chip 显示 `{CODE} {done}/{all}` 字幕进度
- chip 列表超过一行时自动折叠，显示「展开全部 x 种语言 ▾」按钮
- 右侧「添加」按钮打开语言搜索面板

### 6.3 剧集×字幕矩阵

**表格结构**：

| 列 | 宽度 | 固定方式 | 说明 |
|----|------|----------|------|
| # | 70px | sticky left:0 | 集数编号，如「第1集」 |
| 视频文件 | min-width:280px | sticky left:70px | 缩略图 + 文件名 + 时长/大小 + 状态 badge |
| 语言列 ×N | 80px each | 随横向滚动 | 字幕上传状态 |
| 操作 | 60px | sticky right:0 | 操作按钮 |

**横向滚动规则**（15 语言时有 19 列）：
- 表格容器 `overflow-x: auto`
- `#` 列和「视频文件」列使用 `position: sticky` 固定在左侧，不随横向滚动
- 「操作」列 sticky 固定在右侧
- sticky 列与滚动区域之间有 4px 渐变阴影分隔线
- 表格宽度使用 `width: max-content; min-width: 100%`，确保列不被压缩

**视频列状态**：

| 状态 | 显示内容 | 行背景 |
|------|----------|--------|
| uploaded | 缩略图 + 文件名 + 时长·大小 + 「已上传」badge | 默认 |
| uploading | 占位图 + 文件名 + 大小 + 进度条 + 「上传中 x%」badge | 默认 |
| failed | 占位图 + 文件名 + 「上传失败」badge + 错误信息 | coral 浅色 |
| format_error | 占位图 + 文件名 + 「格式错误」badge + 错误信息 | lemon 浅色 |
| pending | 虚线占位框 + 「待上传视频」 | 默认 |

**字幕单元格状态**：

| 状态 | 显示 | 交互 |
|------|------|------|
| uploaded | ✓ 图标 + 文件名 | hover 显示「预览/替换/删除」操作层 |
| empty | + 图标 + 「上传」 | 点击触发上传 |
| disabled | - 图标（灰色） | 不可操作，tooltip 提示原因（如"请先上传视频"） |

### 6.4 批量操作

**批量添加剧集**：
- 弹窗模式（Modal）
- 拖放区域上传视频文件
- 选择文件后展示待添加视频列表，运营确认后批量添加
- 确认后批量添加，新增行有滑入动画

**批量上传字幕**：
- 折叠面板模式（在矩阵上方展开）
- 拖放区域上传字幕文件（SRT/VTT）
- 文件名规则自动匹配集数 + 语言
- 匹配结果预览后确认上传

## 7. 交互约束（通用）

### 7.1 表单校验

- 点击「保存并发布」时触发校验
- 未填必填项：边框变为 coral 色 + 页面滚动到第一个错误项 + 顶部 toast 提示
- 简介字数超限：计数器变红色；达到 90% 时计数器提前变红（预 warn 机制）
- 校验覆盖：§3.1 所有必填项（漫剧名称、作者、剧来源、制作模式、横竖屏）+ EN 多语言内容（剧集名、封面、首页 Banner、简介）

### 7.2 危险操作二次确认
以下操作必须弹出确认框：
- 删除剧集
- 删除字幕文件
- 删除已上传的封面 / 首页 Banner
- 移除语言（提示数据不会丢失）

### 7.3 状态一致性
- 多语言内容管理区的完成度摘要需实时反映实际上传状态
- 剧集管理中的字幕矩阵进度条需与实际数据同步
- 语言增删操作同时影响 Tab 1 多语言区和 Tab 2 字幕矩阵

### 7.4 视觉反馈
- 新增剧集行有滑入动画（fadeIn + translateY）
- Tab 切换有 fade 动画
- 按钮点击有 translate + shadow 消失的按压效果
- Toast 通知从顶部滑入，3 秒后自动消失

### 7.5 搜索与筛选
- 清空搜索框时自动恢复「全部」筛选状态，重置状态筛选为「全部」
- 语言筛选、状态筛选、搜索三者独立作用

## 8. 视频预览 + 字幕检查（技术待评估）

### 需求描述
需求方希望在后台通过视频播放的方式检查字幕效果：
- 在字幕矩阵中，已上传字幕的单元格 hover 可点击「预览」
- 弹出视频播放器，叠加显示对应语言的字幕
- 视频缩略图也可点击触发预览

### 技术风险
- **后台播放器和 App 播放器的渲染效果可能不一致**（字体、排版、特效）
- 建议研发评估：是否能基于 Web 播放器（如 video.js + WebVTT）实现近似效果
- 如果实现成本过高，可降级为「仅显示字幕文本预览」

## 9. 数据模型建议（供参考）

```
Drama {
  id: string
  title: string (EN, 必填)
  series_id: string (系统生成, 如 "#1000058")
  synopsis: string (EN, 必填, ≤500字符)
  tags: string[]              // 有序数组，元素顺序即运营在后台拖拽配置的顺序（见 §3.3），透传至 API 输出，不可由后端按字母/时间重排
  author: string
  owner: string              // 自动设为当前登录用户，只读
  language: string (固定为 EN，只读)
  source: enum (全包采买剧 / 内部剧 / 外部合作剧)
  production_mode: enum (剧转剧 / 文生剧 / 漫转剧 / 成品剧)
  orientation: enum (竖屏 / 横屏)
  category: string (恋爱 / 悬疑 / 奇幻 / 都市 / 古风 / 科幻 / 校园)
  status: enum (draft / published / offline)
  updated_at: datetime

  assets: {
    cover: { [lang]: { url, size, uploaded_at } }     // 每语言独立
    banner: { [lang]: { url, size, uploaded_at } }    // 每语言独立，剧大封面 / 首页 Banner
    logo: { url, size, uploaded_at } | null            // 不分语言
    behind_the_scenes: { url, size, uploaded_at } | null
  }

  translations: {
    [lang]: {
      title: string
      synopsis: string
      source: 'auto' | 'manual'   // 区分机翻和人工
      updated_at: datetime
    }
  }

  episodes: Episode[]
}

Episode {
  ep_number: int
  video: {
    url, size, duration, uploaded_at,
    status: enum (pending / uploading / uploaded / failed / format_error),
    progress: int | null,       // 上传中时的百分比
    error: string | null        // 失败/格式错误时的提示信息
  } | null
  subtitles: {
    [lang]: {
      url, filename, size, uploaded_at,
      status: enum (uploaded / empty / disabled)
    } | null
  }
}
```

| 字段 | 枚举/状态 | 颜色规则 | 说明 |
|------|-----------|----------|------|
| 状态 badge | 已发布 | mint 实色背景 + 黑色描边 | 内容已上线，无需强警示 |
| 状态 badge | 草稿 | gray-light 背景 + 黑色描边 | 中性状态 |
| 状态 badge | 已下线 | coral 实色背景 + 黑色描边 | 需要运营关注 |
| 来源 badge | 全包采买剧 | 显示「全包采买」；mint-light 背景 + mint 描边 + 深绿色文字 | 外部成品/采购链路，作为正向稳定来源 |
| 来源 badge | 内部剧 | 显示「内部」；purple-light 背景 + purple 描边 + purple 文字 | 内部生产链路 |
| 来源 badge | 外部合作剧 | 显示「外部合作」；purple 实色背景 + purple 描边 + 白色文字 | 外部协作链路，视觉权重高于内部剧 |
| 制作模式 badge | 剧转剧 | gray-light 背景 + 黑色描边 + 黑色文字 | 默认生产模式，保持中性 |

| 制作模式 badge | 漫转剧 | 浅蓝背景 + sky 描边 + 深蓝文字 | 漫画转制链路，与来源紫/绿区分 |
| 制作模式 badge | 成品剧 | 白底 + gray 描边 + gray 文字 | 已成品形态，低视觉权重 |
| 完成度 chip | ✓ 已就绪 | mint-light 背景 + mint 描边 | 三项均完成 |
| 完成度 chip | 未完成且百分比 >= 50% | lemon-light 背景 + lemon 描边 | 中度风险 |
| 完成度 chip | 未完成且百分比 < 50% | coral-light 背景 + coral 描边 | 高风险 |
| 原始语言 badge | 任意语言代码 | 黑底白字 | 固定出现在封面左上角 |

### 11.3 完成度 chip

#### 11.3.1 设计原则

列表页职责是**分诊**：哪些剧需要运营关注。采用「例外驱动」设计——正常的安静，异常的凸显。

#### 11.3.2 显示规则

每张剧集卡片底部显示 **1 个** completion chip：

| 场景 | chip 内容 | 颜色 | 含义 |
|------|----------|------|------|
| 视频、字幕、语言三项均 ≥100% | `✓ 已就绪` | mint（绿色） | 无需关注 |
| 存在未完成项 | `{最差维度} {百分比}%`，如 `字幕 19%` | coral（<50%）或 lemon（≥50%） | 显示瓶颈维度 |

#### 11.3.3 三项完成度计算

| 维度 | 分子 | 分母 | 说明 |
|------|------|------|------|
| 视频 | 已上传视频集数 | 剧集矩阵中的总行数 | |
| 字幕 | 已上传字幕文件数 | 剧集矩阵总行数 × 已配置语言数 | |
| 语言 | 已完成配置的语言数 | 已配置语言数 | 语言完成 = 剧集名+封面+Banner+简介 均已填写 |

#### 11.3.4 hover 交互

hover 任意 chip 时，弹出 tooltip 展示三项明细：

```
视频    12/24 (50%)
字幕     9/48 (19%)
语言     2/3  (67%)
```

- 每行右侧数值带颜色编码：mint（≥100%）、lemon（≥50%）、coral（<50%）
- tooltip 出现在 chip 上方，白色背景 + 边框 + 阴影

#### 11.3.5 边界场景

| 场景 | 决策 |
|------|------|
| 0 集时 | 显示「✓ 已就绪」（无视频需要上传） |
| 两个维度百分比相同 | 按固定优先级取第一个：视频 > 字幕 > 语言 |
| 已下线的剧是否显示 chip | 显示，数据仍有效 |
| 字幕分母 | 用「已配置语言数」作为分母（不是全部 15 语言） |
